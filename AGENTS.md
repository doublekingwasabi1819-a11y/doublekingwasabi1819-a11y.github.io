# Agent instructions

- This is a static GitHub Pages website. Edit the root `index.html`; there is no framework or build step.
- Preserve the owner's requested scope. The initial page is intentionally minimal.
- Keep `.nojekyll` so GitHub serves the files directly.
- GitHub Pages publishes the repository root from `main`. After an authorized push, verify the Pages deployment in Actions.
- Use the owner's authorized GitHub connection for writes. Never commit credentials.
- Do not use ChatGPT Sites deployment tools for this repository.

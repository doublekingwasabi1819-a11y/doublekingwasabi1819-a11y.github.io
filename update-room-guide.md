# Using the Update room

1. Coordinate with other workers before editing the same files.
2. Open **Update room**, choose **New update**, and submit complete changed text files with a short explanation of what you tested.
3. Choose **Run checks** and review the exact source and results.
4. Follow the manager policy: one eligible account (default), manager only, or two distinct agents. Agents can review their own updates only when the manager enables that option. Each account counts once.
5. When green, the manager can choose **Update site**. The manager can also choose **Publish with my approval** to override review requirements; successful checks and current source are still required. Wait for **Live-site deployment complete** before calling it live.

Configure approvals in **Account → Studio settings → Update approvals → Manage update approvals**. Publishing remains manager-only.

Red means attention is needed. Amber means preparation, checks, or reviews are pending. Green means the exact version is ready for the manager.

Changing files or the starting commit clears old sign-offs. If another update changes the source first, reconcile with the latest version before submitting again.

Messages do not automatically start another agent conversation. Each worker must be active to read and act on them.

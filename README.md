# CoderCode Website

A minimal public website owned by `doublekingwasabi1819-a11y`, hosted with GitHub Pages.

## Editing the website

The homepage is `index.html` in the repository root. It contains the page, styles, and favicon. No dependencies or build step are needed. Open it in any browser to preview changes.

GitHub Pages is configured to publish the root folder of the `main` branch. Commits to `main` automatically trigger publication; check the repository's Actions tab for deployment status.

## For Codex agents

1. Open this repository through the owner's authorized GitHub connection or clone it locally.
2. Edit `index.html` and any assets required by the owner's request.
3. Preview the result and check links and any JavaScript you add.
4. Commit and push approved changes to `main`; confirm that the Pages deployment succeeds.

This is ordinary GitHub Pages hosting. No ChatGPT Sites tools or configuration are required.

Anyone can read this public repository and the website. Publishing changes requires GitHub write access granted by the owner. The public URL alone does not grant write access.

Keep credentials and private data out of this public repository.
